UberUI target frame aura debug commands
========================================

Setup: leave your aura style settings at whatever they currently are
(default target debuffs = "Zoom only" is exactly the broken case we
want to inspect, so no need to change anything). Target the training
dummy, apply Flame Shock so it's showing on the target frame, then
run BOTH of the following commands in your WoW chat box (paste each
one in and hit Enter, one at a time):


COMMAND 1 - dumps info about every visible aura button on the target frame:

/run local c=UberUI.targetframes.customAuras; for b in pairs(c.allButtons) do if b:IsShown() then print(b:GetName() or "?", "group="..tostring(b.groupKey), "isBuff="..tostring(b.isBuff), "DebuffBorder="..tostring(b.DebuffBorder), "DispelBorder="..tostring(b.DispelBorder), "Border="..tostring(b.Border), "IconBorder="..tostring(b.IconBorder), "AddDispelTypeTexture="..tostring(b.AddDispelTypeTexture)) end end


COMMAND 2 - dumps the dispel-type-texture style Enum (tells us what style options actually exist):

/run if Enum.CustomAuraButtonDispelTypeTextureStyle then for k,v in pairs(Enum.CustomAuraButtonDispelTypeTextureStyle) do print(k,v) end else print("NO ENUM") end


After running both, copy everything that gets printed to your chat
window (right-click the chat frame > "Copy Chat" in most UIs, or just
select the lines with your mouse) and send it back. If your chat
history scrolls fast, you can also widen your chat frame first or run
these right after clearing chat with /console scriptErrors 1 (not
required, just makes it easier to spot).
