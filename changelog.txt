=== Retail / Classic ===

12.0.0.0:
    - Update 12.0.0.
    - Added "Icon Zoom" options to enlarge aura icons on Player, Target, Party, and Raid frames.
        - Borders no longer can work correctly as you cannot differentiate between dispellable vs non-dispellable buffs.
    - Added "Damage Meters" customization:
        - Added options to texture damage meter bars.
        - Added options to show/hide background and adjust transparency.
        - Added options to hide the bar overlay (shine) and bar background texture.
    - Improved "Bar Textures" settings with a new collapsible "Show Extended Bar Textures" option to declutter the menu.
    - Fixed Bag Slot coloring on the main menu bar (including Backpack).
    - Fixed various texture and coloring persistence issues.

12.0.0.1:
    - Fix nameplate texture overriding call in options menu

12.0.7:
    - Updated for WoW Patch 12.0.7.
    - Added new customization options to independently texture the Personal Resource Display bar.
    - Added an option to darken the Personal Resource Display border texture.

12.1.0:
    - Fixed UI taint and errors during combat by deferring frame updates until combat ends (arena, party, player, and target frames).
    - Updated class color retrieval methods for improved compatibility.
    - Target frame debuffs now show Blizzard's real dispel-type border colors, and dispellable/stealable enemy buffs show the native white border -- only for classes that can actually Purge/Dispel Magic/Spellsteal.
    - Rebuilt Focus frame buffs/debuffs on the same reliable system as Target frame, fixing longstanding sizing and display bugs.
    - Added "Show Dispels for Target Buffs" and "Show Dispels for Focus Buffs" options (on by default).
    - Added "Focus Bar Textures" option (the feature already worked, it was just missing from the menu).
    - Added "Zoom Party Auras" option.
    - Fixed "Small Friendly Nameplates" not applying, and fixed a follow-up bug that was forcing all friendly nameplates to a fixed large size by default.
    - Fixed "Cooldown Bar Textures" option not applying to Cooldown Manager viewer bars.
    - Fixed settings occasionally not being read back correctly after a UI reload.
    - Fixed a Lua taint error affecting nameplate health text.
    - Removed the non-functional "Class Color Arena Targets" and "Class Color Friendly/Enemy Nameplates" options (redundant with current Blizzard defaults).
    - Removed leftover internal debug tooling.

=== WoW Forever ===

1.60.1:
    - Initial update/compatibility pass for the WoW Forever client, build 1.60.1.
    - See 12.1.0 above for the full list of changes -- all developed and tested on this build.
