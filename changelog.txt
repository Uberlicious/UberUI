1.0.0:
    - First release under the new versioning scheme: the addon version is now independent of the WoW patch number, since one package now covers both retail and WoW Forever. See the Interface line for client compatibility instead.
    - Aura styling (Zoom / Dark Border / Both / None, with real dispel-type-colored borders) is now available on Player, Target, Focus, Party, Compact Raid/Party (including private boss debuffs and the Big Defensive icon), Arena (Crowd Control and Diminishing Returns trackers), and Boss frames.
    - Frame darkening, bar texture customization, and health bar coloring extended to cover all of the above frame types, plus bag slots, action bar dividers, and the damage meter.
    - Hide Honor (hides the PvP badge/icon) now works correctly on Player, Target, Focus, and Party frames, on both retail and WoW Forever.
    - Fixed UI taint and errors during combat by deferring frame updates until combat ends (arena, party, player, target, and nameplate frames).
    - Compatibility pass for the WoW Forever client (build 1.60.1) alongside retail.
    - Arena Nameplate Numbers: shows 1/2/3 over enemy nameplates instead of their name while inside an arena.
    - Most settings that used to need a UI reload to take effect (Hide Honor, Arena Nameplate Numbers, compact raid/party bar textures, Hide Raid Frame Titles, Personal Resource border/texture) now apply live, and stale "requires reload" tooltips were corrected.
    - Cooldown Manager icon borders now use the same border style and sizing logic as the rest of the addon's aura borders, and stay correctly sized when Edit Mode's icon size/padding settings change.
    - Fixed Hide Nameplate Selection Glow not restoring the glow when turned back off.
    - Reduced unnecessary hook installation addon-wide for better taint hygiene: optional features no longer install their hooks unless actually enabled.
    - Deduplicated the Bar Textures settings code (12 near-identical blocks reduced to one shared helper).
    - Settings reorganized into pages: Uber UI (general), Unit Frames, Raid & Group Frames, Arena, Nameplates, and Other UI. Existing saved settings carry over unchanged. /uberui now works alongside /uui.
    - Aura settings are clearer: each frame now has Zoom Icons, Buff Border, Debuff Border, Border Shape, Border Thickness, and Border Position instead of a single combined style dropdown. Existing looks carry over unchanged.
    - New Square aura borders (Border Shape: Square) for every aura location, with adjustable pixel thickness (default 2px) and inside/outside placement. Debuffs keep their real dispel-type colors, including in combat on Target, Focus, Boss, and Compact Raid/Party. With Square borders, your own debuffs are shown by Uber UI itself (following your Edit Mode Debuff Frame layout) so their dispel colors stay correct in combat too.
    - Debuff Border "Dispel Color" with Rounded borders uses Blizzard's own full-brightness dispel-type border art (the colors were coming out too dark), and is now correct in combat on Player debuffs too.
    - New All Auras section on the main settings page: one-shot actions that set Zoom, borders, shape, thickness, or position on every aura location at once.
    - Fixed the Target/Focus buff row overlapping the debuff row during combat.
    - Fixed Hide Honor force-showing PvP badges that Blizzard wouldn't show (and stray badge art on WoW Forever); Hide Honor now also covers WoW Forever's own PvP badge.
    - Compact Raid/Party Big Defensive no longer shows permanent auras such as Devotion Aura.
    - Dispel-colored square borders (and purgeable-buff highlights) are drawn 1px thicker than dark borders so the color is easier to see.
    - Square-bordered aura icons now fill their whole slot instead of shrinking by 1px on each side.
    - Target and Focus auras now match Blizzard's sizes and spacing: 21px for your own auras, 17px for others, and 3px between icons, rows, and the buff/debuff blocks. Focus auras were previously smaller.
    - Fixed extra space above an enemy target's buffs when it has no debuffs.
    - New Darken Addon Minimap Buttons option (Other UI, on by default): darkens the ring around other addons' minimap buttons to match the minimap.
    - New Uber UI Nameplate Auras option (Nameplates page, off by default): nameplate buffs, debuffs and crowd control shown in Uber UI's own styled icons, in Blizzard's positions and following Blizzard's nameplate aura settings, with the usual zoom, border, shape, thickness and position options. May slightly increase loading screen times.
    - Nameplate aura extras: countdown numbers with configurable normal and expiring colors (color pickers) and an expiring threshold (1-10 s), a thin white border on purgeable buffs, and an optional Pandemic Highlight (border, proc glow or marching ants, with a color picker) while one of your debuffs can be refreshed without losing time.
    - Target auras: purgeable buffs now get a thin rounded white border instead of Blizzard's large glow.
    - New Target of Target / Focus Target of Target options: narrow the aura rows while target-of-target is shown (Blizzard's behavior) or move the target-of-target frame aside so the rows keep their full width.
    - Custom nameplate bar textures now keep Blizzard's bar shape and edge, so the nameplate border reads as sitting in front of the bar again, and no longer revert to Blizzard's texture after nameplate style changes.
